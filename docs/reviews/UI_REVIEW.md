## 0. 结论先行

**这是一个"形神都像 Advanced IP Scanner"的界面 —— 而且做得相当到位。** 源码注释里直接写着"仿 AIP"，13 列布局、服务子项跨列展开、左侧大扫描按钮 + 右侧绿色/黄色小工具按钮、底部状态栏，都是对 AIP 的忠实复刻。信息密度、键盘快捷键覆盖（30+ 个）、i18n 纪律、双主题，都明显强于同类个人项目。

**但它同时继承并放大了 AIP 的两个历史包袱：**

1. **单面板架构** —— 全应用只有"工具栏 + 一张 13 列表格"，没有任何详情面板。所有富信息（WMI 硬件、NetBIOS、SNMP sysDescr、共享、OS 细节）被迫塞进 **tooltip 和跨列子项**。AIP 至少有底部详情栏，这里连这个都没有。
2. **2010 年的视觉语言** —— 2px 圆角、`#F0F0F0` 系统灰、图标按钮无文字、13 列同时铺开、无空状态、无渐进式披露。今天的同类产品（Fing、SolarWinds、Auvik）已经全面转向"概览卡片 + 主从布局 + 语义配色"。

**一句话建议**：**先补"详情面板"和"空状态/扫描态"，再谈视觉翻新。** 前者是架构级的体验缺口，后者才是皮肤问题。详见第 3 节的 P0/P1/P2 分级。

## 1. 现状盘点

### 1.1 布局结构

`main_window.py::_init_ui()` 构建的是一条**单列垂直堆叠**：

```
┌──────────────────────────────────────────────────────────────┐
│ Row1: [扫描][暂停] [本机子网][C类][展开][收起]          ← 6 个图标按钮 │
├──────────────────────────────────────────────────────────────┤
│ Row2: [IP 范围输入框 ──────────────]   搜索 [________]        │
├──────────────────────────────────────────────────────────────┤
│ ───────────────────── 分隔线 ─────────────────────            │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   QTreeWidget · 13 列 · 可展开服务子项                        │
│                                                              │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ [==== 进度条 ====]  （默认隐藏）                               │
├──────────────────────────────────────────────────────────────┤
│ 状态栏: 就绪 | 统计 | 地址库: 空                               │
└──────────────────────────────────────────────────────────────┘
```

| 维度 | 现状 |
| --- | --- |
| 顶层容器 | 单一 `QVBoxLayout`，**无 `QSplitter`、无 `QDockWidget`、无 `QStackedWidget`** |
| 主视图 | `QTreeWidget`，13 列（隐藏第 9 列"服务"） |
| 详情承载 | **无详情面板**；靠 `setToolTip`（IP 列的 tip 会拼到 10+ 段）与展开子项 |
| 工具栏 | 2 行；6 个纯图标按钮（`setFixedSize` 固定像素） |
| 菜单 | 7 个顶级菜单：文件/扫描/分析/设置/查看/工具/帮助 |
| 对话框 | 11 个独立 `QDialog`（`ui_dialogs.py`） |

### 1.2 主题系统

- `assets/styles/light.qss`（343 行）+ `dark.qss`（343 行）双份**镜像**样式表，`styles.py` 以 fail-fast 方式加载（缺失即抛错，设计合理）。
- 字体：`QFont("Microsoft YaHei", 9)`，QSS 内多为 13px / Consolas 用于 IP、MAC、端口列。
- 主色：`#0078D7`（Windows 10 蓝）。
- 深色模式：`Fusion` + `_build_dark_palette()`，支持**按时间自动切换**（18:00–次日 06:00）。

### 1.3 已有的亮点（不要动）

| 亮点 | 说明 |
| --- | --- |
| 服务子项跨列展开 | `setFirstColumnSpanned` 仿 AIP，带 `_ROLE_SVC_SIG` 签名避免重建闪烁 —— 这是个**很细腻**的优化 |
| 增量渲染 | `_upsert_table_row` 边扫边出，离线行按筛选即时隐藏 |
| 快捷键覆盖 | F5/Esc/Ctrl+E/Ctrl+P/Ctrl+1..3/Ctrl+U/Ctrl+T… 共 30+ 个 |
| 排序键分离 | `Qt.UserRole` 存数值键，IP/响应时间按数值排序而非字符串 |
| i18n 纪律 | 665 条词条，语言无关规范值 + 惰性 `tr()`，有 AST 校验测试 |
| 拓扑视图 | `TopologyDialog` 真实拓扑 + 星型回退，是**差异化功能** |
| 主题随图标重绘 | 切主题时工具栏矢量图标线条色同步刷新 |

## 3. 改进建议（按优先级）

### P0-1　补一个「详情面板」—— 最高性价比的单项改造

**问题**：现在一台设备的完整画像要分三个地方看 —— 13 列表格（截断）、tooltip（`_set_item_data` 里 IP 列 tip 会拼 10+ 段、长到无法阅读）、展开子项（只有服务/WMI/NetBIOS）。AIP 有底部详情栏，这里没有。

**建议**：在表格下方加 `QSplitter` + 详情面板（可折叠、可拖拽、状态持久化）。选中行时按**分区卡片**呈现：

```
┌─ 192.168.1.42 · 在线 · 响应 3.2ms ──────────────────[复制][重扫]─┐
│ 身份      主机名  DESKTOP-A1B2   制造商  Dell Inc.   型号  OptiPlex 7090 │
│ 网络      MAC  3C:52:82:xx:xx:xx  网关 192.168.1.1   VLAN  —            │
│ 系统      Windows 10 Pro (TTL 128) 登录用户  CORP\alice   SN  ABC123      │
│ 服务      22/SSH  OpenSSH 8.9 │ 445/SMB  Windows 10 │ 3389/RDP  Windows   │
│ 风险      ⚠ IP 冲突：与 3C:52:82:yy:yy:yy 共用 192.168.1.42              │
└────────────────────────────────────────────────────────────────────────┘
```

**收益**：13 列可以精简（详情面板接管长字段），tooltip 回归"补充"而非"唯一通道"，冲突/变更/风险有地方呈现。

**落点**：`main_window.py::_init_ui()` 的 `main_layout.addWidget(self.table, 1)` 处替换为 `QSplitter(Qt.Vertical)`；新增 `detail_panel.py`；在 `_on_item_clicked` / `currentItemChanged` 里刷新。

---

### P0-2　补「空状态」与「扫描态」

**问题**：首次启动是一张**全空白表格**，没有引导、没有上一步、没有 CTA。扫描过程中只有底部一条进度条和一行状态栏文字，用户不知道"现在在干嘛、还要多久、扫到几台"。

**建议**：

1. **空状态**：用 `QStackedWidget` 包住表格。无结果时显示：
   - 大号主 CTA「扫描本机子网」（当前网段自动填好）
   - 次要动作：最近一次扫描摘要（时间 / 在线数 / 新增数）
   - 一行说明："扫描级别：快速 · 端口 22/80/443/3389"
2. **扫描态**：在工具栏下方加一条**扫描摘要条**（`QFrame`），实时刷新：
   ```
   阶段: 端口探测 ▸  已扫 87/254   在线 12   有服务 7   用时 00:14   [停止]
   ```
   并给正在扫的行加"进行中"视觉态（行首小 spinner 或淡化处理）。当前 3 阶段管线（Ping→ARP→mDNS→富化）在 UI 上完全不可见，用户只看到一个百分比。

**落点**：`scan_mixin.py` 已有 `_on_progress(current, total, ip)` 与 `log_signal`，扩展信号即可；摘要条在 `main_window.py` Row2 下方插入。

### P1-1　工具栏：图标加文字、动作分组

**问题**：`_init_ui()` 里 6 个按钮全是**纯图标 + tooltip**（`_make_tool_icon("ip"/"c"/"expand"/"collapse")`）。问题有三：

- 自绘图标语义模糊（"ip"/"c" 两个绿按钮，不 hover 不知道区别）；
- **"展开/收起"是视图操作，却和"扫描"并排**，动作语义混杂；
- `setFixedSize(100, 36)` / `setFixedSize(36, 36)` 写死像素，高 DPI 下会错位。

**建议**：

```
[▶ 扫描]  [■ 停止]   │  [本机子网] [C 类网段]   │   ⋯ 更多
   ↑ 主按钮带文字        ↑ 预设带文字             ↑ 视图/展开收起收进溢出菜单
```

- 主次动作分两组，中间加 `QFrame` 竖分隔；
- 扫描/停止/子网预设**带文字标签**（图标+文字是 AIP 与 Fing 的共识）；
- 展开/收起这类低频视图操作移到「查看」菜单（那里已有 `Ctrl++`/`Ctrl+-`）；
- 用 `setMinimumSize` + `sizeHint` 替代 `setFixedSize`。

---

### P1-2　13 列 → 「列预设」

**问题**：「显示列」菜单是 **13 个独立 checkbox**，用户要自己拼组合。而 13 列同时铺开在 1366 宽的屏上必然横向滚动。

**建议**：改为**预设 + 自定义**：

| 预设 | 列 |
| --- | --- |
| 巡检（默认） | IP · 状态 · 主机名 · MAC · 制造商 · 响应时间 |
| 资产 | IP · 状态 · 主机名 · MAC · 制造商 · 位置 · 使用者 · 设备类型 · 备注 |
| 安全 | IP · 状态 · 开放端口 · 服务 · 操作系统 · 风险 |
| 全量 | 13 列全开 |

保留自定义入口，但默认给预设。落点：`main_window.py` 的 `_col_actions` dict 改为预设定义表。

---

### P1-3　扫描预设与设备收藏（AIP 的招牌功能）

**问题**：网段会持久化（`_load_settings`），但**没有命名预设**，也没有**设备收藏**。MAC 地址库是"资产台账"，不是"常用设备"。AIP 用户最常用的两个动作这里都缺。

**建议**：

- **扫描预设**：把「网段 + 扫描级别 + 端口集 + 探测方式」存成命名配置（"办公网日常" / "机房全端口"），工具栏下拉一键切换；
- **设备收藏**：右键「加入收藏」，收藏设备在表格里带星标并可一键过滤。落点：复用现有 `ipscanner.ini` / SQLite。

---

### P1-4　筛选的可见性与"结果被藏起来"的困惑

**问题**：默认筛选是「仅在线」，且**筛选控件在菜单里**（工具栏只留了一个隐藏的 `filter_combo` 作值载体）。用户扫 /24 扫出 254 条、界面只显示 12 条时，会以为程序坏了 —— 这是新手最常见的困惑。

**建议**：把筛选做成**可见的筛选条**，每个 chip 带计数：

```
[全部 254] [● 在线 12] [○ 离线 242] [有服务 7] [冲突 1] [新增 3]
```

计数本身也是信息（"242 台离线"一眼可见）。落点：`filter_combo` 换成 `QToolBar` + 可勾选按钮，复用 `_item_matches_filter`。

---

### P2-1　视觉语言现代化

当前是**纯功能主义**：2px 圆角、`#F0F0F0` 灰、无阴影、无留白节奏、无强调色层次。

**建议**（保持双主题同步）：

1. **定义设计令牌**：间距 4/8/12/16、圆角 4/6、语义色（成功 `#16A34A`、警告 `#D97706`、危险 `#DC2626`、信息 `#0078D7`）—— 现在这些色散落在 `main_window_tree.py` 里硬编码（`QColor(22,163,74)` / `QColor(220,38,38)` / `QColor(217,119,6)`）。
2. **行高与密度**：`QTreeWidget::item { min-height: 26px }` 写死；建议给「紧凑 / 舒适」两档。
3. **表头**：现在是 `#E8E8E8` 纯色块；建议加轻微下边框与排序指示器高亮。
4. **统一圆角**：现在按钮 2px、输入框 1px、表格 0px —— 建议统一到 4px。

### P2-2　消除「内联样式」造成的主题漂移风险

**问题**：`styles.py` 的注释明确写了"QSS 文本从 .py 拆出去，改配色不必动 .py"—— 但 `main_window.py` 里仍有多处**硬编码内联样式**：

```python
self.range_list_label.setStyleSheet("color: #0078D7; font-size: 11px; ...")
self.status_stats_label.setStyleSheet("color: #333333; font-size: 12px;")
self.excel_label.setStyleSheet("color: #888888; font-size: 11px;")
self.sep.setStyleSheet("color: #CCCCCC;")
```

`_apply_theme()` 里又用**另一组硬编码色**（`#4DA6FF` / `#9AA0A6` / `#C8C8C8` / `#3F3F46`）去覆盖它们。结果是：**主题色定义在两处**，新增一处内联样式就会在深色下"漏白"。

**建议**：给这些 label 设 `setObjectName("mutedLabel" / "accentLabel" / "statsLabel")`，颜色全部写进 `light.qss` / `dark.qss`；`_apply_theme()` 只需切样式表，不再逐控件改色。

---

### P2-3　右键菜单过长

`_show_context_menu` 单层平铺了 **20+ 个动作**（复制×4、重扫、WoL、WMI、NetBIOS、工具子菜单×8、地址库×3…）。建议收敛为分组：

```
复制 ▸        （IP / MAC / 主机名 / 整行）
连接 ▸        （HTTP / HTTPS / RDP / SSH / Telnet / 共享文件夹）
管理 ▸        （WoL / WMI 识别 / NetBIOS 识别 / 远程关机 / 远程重启）
地址库 ▸      （加入 / 编辑 / 删除）
重新扫描此 IP
```

---

### P2-4　高 DPI 与无障碍

| 问题 | 现状 | 建议 |
| --- | --- | --- |
| 固定像素 | `setFixedSize(100,36)`、列宽写死 130/78/140… | 改用 `setMinimumSize` + `sizeHint`，列宽按 DPI 缩放 |
| 最小窗口 | `setMinimumSize(1200, 750)` | 1366×768 笔记本上占满屏；降到 `1024×640` 并让列可横向滚动 |
| 焦点环 | `QTreeWidget { outline: 0 }` 移除了焦点指示 | 保留 `outline`，或自定义 `:focus` 边框（键盘用户必需） |
| 仅靠颜色 | 在线绿 / 离线红 | **已有图标 + 文字**，这点做得好，保持 |
| 状态列 | 图标是**预渲染位图**（`_make_pc_pixmap`） | 高 DPI 下需按 `devicePixelRatio` 重绘 |

### P3　差异化机会（本项目独有，值得放大）

1. **变更时间线**：已有 `change_detector` + `history_store`，但只活在对话框里。建议在主界面加「变更」筛选 chip + 行内 badge（`＋新增` / `↑ 改址` / `✗ 消失`），把"对比两次快照"从主动操作变成常驻视图。
2. **概览仪表盘**：`SubnetUtilizationDialog` 已经算出了在线率/分布 —— 把它提升为**启动即见的概览页**（设备总数、在线率、新增、异常、Top 厂商），Fing 正是靠这个出圈。
3. **跟随系统主题**：现在按**时钟**切主题（18:00–06:00）比较少见；建议改为跟随 Windows 系统深浅色（读注册表 `AppsUseLightTheme`），把"按时间"降级为选项。
4. **风险列/评分**：已有冲突检测 + 指纹库 + 明文协议识别（Telnet/SNMP v2c），完全够算一个"风险"列。
