# IPScanner 运行时依赖
#
# ── 为什么全部锁到 `==` ──────────────────────────────────────────────
# 原先写的是 `>=`（PyQt5>=5.15.11 / openpyxl>=3.1.5 / xlrd>=2.0.1），
# 意味着任何一次全新安装都可能拉到未经本项目验证的新版本。桌面 GUI 对
# Qt 小版本差异尤其敏感（sip ABI、QSS 解析、高分屏行为都变过），一旦上游
# 引入不兼容改动，用户侧的表现是"装完就崩"，而不是一句可读的报错。
#
# ── 升级流程 ────────────────────────────────────────────────────────
#   1. 改本文件里的版本号
#   2. python run_tests.py           # 单元测试全绿
#   3. 手动跑一次 GUI 冒烟（扫描 / 导出 / 拓扑 / 语言切换）
#   4. 同步 pyproject.toml 的 dependencies
#
# ── 环境要求 ────────────────────────────────────────────────────────
#   Python 3.10 ~ 3.13（CI 矩阵见 .github/workflows/ci.yml）
#   Windows 为主平台；macOS / Linux 亦可用（WMI 识别仅 Windows）

# GUI 框架。三件套版本必须匹配：单独升 PyQt5 而不管 PyQt5_sip 会踩 ABI 不兼容，
# 典型症状是 import 阶段就抛 "DLL load failed" 或 sip 版本断言失败。
PyQt5==5.15.11
PyQt5-Qt5==5.15.2
PyQt5_sip==12.18.0

# Excel 设备清单导入 / 导出
openpyxl==3.1.5
xlrd==2.0.2
