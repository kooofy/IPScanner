# ── 静态检查 ────────────────────────────────────────────────────────

# 语法错误），不开格式类规则 —— 目的是把真实缺陷挡在门外，而不是制造
# 大面积的风格 diff。配置见 pyproject.toml 的 [tool.ruff.lint]。
# 用法：python -m ruff check .
ruff==0.16.8

# ── 类型检查 ────────────────────────────────────────────────────────
# ⚠ **版本必须锁死**：pyright 每次升级都可能新增规则或收紧推断，把以前干净的
# 文件报红。本项目的门禁要求 0 error，所以升级 pyright 要当成**一次有意的变更**
# 来做（改版本号 → 看报了什么 → 逐个处理），不能让它自动跟 latest。
# 检查范围见 pyproject.toml 的 [tool.pyright]（是**包含清单**，不是排除清单）。
# 用法：python -m pyright
pyright==1.1.414

# ── 覆盖率 ──────────────────────────────────────────────────────────
# 用 coverage 而不是 pytest-cov：本项目跑的是**标准库 unittest**（run_tests.py），
# 压根不经过 pytest。
# 用法：coverage run run_tests.py && python check_coverage.py
# ⚠ 下界是 **per-file** 的（`history_store.py` / `db_util.py`），不是全局百分比 ——
#    全局数字会被与本次改动无关的 0% 文件稀释，制造假红。理由见
